# js-practice

Práctica y ejercicios del curso **JavaScript desde cero** de [mouredev pro](https://mouredev.pro).

## Estructura

- `practica/`: el código que voy escribiendo mientras sigo las lecciones del curso.
- `ejercicios/`: los ejercicios de cada tema, resueltos por mí sin ayuda de IA.

## Temas del curso

Introducción, primeros pasos, operadores, strings, condicionales, estructuras, bucles, funciones, objetos, desestructuración y propagación, clases, manejo de errores, console y módulos.
